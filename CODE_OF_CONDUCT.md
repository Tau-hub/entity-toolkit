# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1, which applies in issues, pull requests, the wiki and any space where the project is represented.

In short: be respectful and patient, welcome people whatever their experience, accept criticism of the work (not of the person), and do not harass, insult or publish other people's private information (player names, accounts).

**Reporting.** Report a behaviour that breaks these rules by opening a confidential [security advisory](https://github.com/Tau-hub/entity-toolkit/security/advisories/new) on the repository (it is private to the maintainer) or, for something already public, by flagging the comment to GitHub. The maintainer may edit or remove comments, close issues and block people who do not follow the rules.
