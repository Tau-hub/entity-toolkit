Setup

First launch checklist

1Game and Windows requirements

  • Dead by Daylight in English (the toolkit reads the game's English menu text) and in borderless / windowed display mode, not exclusive fullscreen.
  • An English language pack for Windows OCR (Settings → Time & language → Language & region). checking…
  • Play on the screen the toolkit captures: it grabs the monitor the game is on.

2Download the data

Perk names, descriptions and icons (DbD wiki), map names, Otzdarva's builds and tier list, and NightLight's community stats. Nothing from these sites ships with the toolkit: it is downloaded on your PC, into the data folder. Run it again after a game patch.

3You

Your in-game name, exactly as shown on the end-of-match scoreboard: it is how the toolkit finds your row to tick “Me” on NightLight.

4Your character levels

Tell the toolkit which characters you own and how far you got with each one, once: tick them by hand, or drop screenshots of the in-game killer / survivor selection screens and let it read the levels. After that it keeps them up to date from the scoreboard.

5NightLight optional

To send the scoreboard to nightlight.gg and have the match reviewed for you (the toolkit ticks “Me”, sets the map and confirms):

  • Create an API token in your NightLight account settings and paste it here. It is saved only in data/nightlight_token.txt and sent only to api.nightlight.gg.
  • Sign in once in the browser window the button opens (Edge). No password is read or stored by the toolkit.

6Options

How the toolkit is triggered

In automatic mode, while the game is in front, the toolkit looks at a thin strip at the top left of the screen every 2 seconds (about 30 ms each time), and a few times right after you press Tab. It is the same screenshot technique as the capture key, nothing more: the game itself is never read. The capture key below keeps working in both modes, for instance to send a scoreboard before everyone has finished. Changing the mode applies within a few seconds, no restart needed.

Shortcuts look like alt+numpad7, ctrl+shift+n, f9. Changing them takes effect the next time the program starts.

Every press of the capture key (Tab menu, scoreboard…) is saved in data/captures, the oldest being deleted beyond that number. They stay on your PC: useful to understand a wrong reading.

With Start automatically with Windows below, this means the page opens by itself each time you launch Dead by Daylight.

When this is on, a tiny watcher starts when you sign in to Windows (it only checks the process list every few seconds). Entity Toolkit starts by itself when Dead by Daylight starts, and closes by itself when Dead by Daylight closes; the watcher then waits for the next launch. Turn it off to start the toolkit by hand with run.bat instead.

A patch can add killers, survivors, perks, add-ons or maps. While the toolkit runs, it checks once in a while whether the chosen delay has passed and then refreshes everything in the background (a few MB, no effect on the game). It never does it before you have done the first download yourself.

You can come back to all of this later: the Setup button becomes ⚙ Settings (top right).

Reset

Shows the first-launch setup again. Your downloaded data, levels, builds, NightLight token and options are kept.
