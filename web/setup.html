Setup

First launch checklist

1Game and Windows requirements

  • Dead by Daylight in English (the toolkit reads the game's English menu text) and in borderless / windowed display mode, not exclusive fullscreen.
  • An English language pack for Windows OCR (Settings → Time & language → Language & region). checking…
  • Play on the screen the toolkit captures: it grabs the monitor the game is on.

2The data

Perk names, descriptions and icons (DbD wiki), map names, Otzdarva's builds and tier list, and NightLight's community stats. A copy comes with the toolkit, so there is nothing to wait for; it is then kept current on your PC, in the data folder. The lists and texts are read again at each update, and only the icons you do not have yet are downloaded.

Hotkey or automatic

How do you want the toolkit to read the players menu and the scoreboard?

In automatic mode, at the start of the match, press Tab and keep the menu open about one second, with the mouse away from the perk icons: a tap shorter than half a second can be missed (press Tab again). While the game is in front, the toolkit looks at a thin strip at the top left of the screen every 2 seconds (about 30 ms each time), and a few times right after you press Tab. It is the same screenshot technique as the capture key, nothing more: the game itself is never read. The capture key below keeps working in both modes, for instance to send a scoreboard before the match is over for everyone. Changing the mode applies within a few seconds, no restart needed.

Shortcuts look like alt+numpad7, ctrl+shift+n, f9. A new shortcut takes effect the next time the toolkit starts.

Your in-game name

Your in-game name, exactly as shown on the end-of-match scoreboard: it is how the toolkit finds your row to tick “Me” on NightLight.

5NightLight optional

You do not use NightLight? Just press Next. Without a token the toolkit never sends anything: it only shows the perks.

To send the scoreboard to nightlight.gg and have the match reviewed for you (the toolkit ticks “Me”, sets the map and confirms):

  • Get your API token on NightLight: nightlight.gg/account/api (sign in there first, create a token, copy it) and paste it here. It is saved only in data/nightlight_token.txt and sent only to api.nightlight.gg.
  • Sign in once in the browser window the button opens (Edge). No password is read or stored by the toolkit.

4Your character levels

Tell the toolkit which characters you own and how far you got with each one, once: tick them by hand, or drop screenshots of the in-game killer / survivor selection screens and let it read the levels. After that it keeps them up to date from the scoreboard.

Optional. Reading screenshots takes a moment: you can press Next and do it later from the Levels page.

6Options

The defaults suit most players: you can leave this page as it is. Everything here, and on the previous pages, can be changed later in ⚙ Settings.

Every press of the capture key (Tab menu, scoreboard…) is saved in data/captures, the oldest being deleted beyond that number. They stay on your PC: useful to understand a wrong reading.

With Start automatically with Windows below, this means the window opens by itself each time you launch Dead by Daylight. It reopens where you left it (your second screen, for instance).

Installing downloads the release, checks its SHA-256 against the one published with it, replaces the program (never your data folder) and restarts the toolkit. With the Python version from a git clone, it runs git pull and refreshes the packages.

When this is on, a tiny watcher starts when you sign in to Windows (it only checks the process list every few seconds). Entity Toolkit starts by itself when Dead by Daylight starts, and closes by itself when Dead by Daylight closes; the watcher then waits for the next launch. Turn it off to start the toolkit by hand with run.bat instead.

A patch can add killers, survivors, perks, add-ons or maps. While the toolkit runs, it checks once in a while whether the chosen delay has passed and then refreshes everything in the background (a few MB, no effect on the game). It never does it before you have done the first download yourself.

All set

You can come back to all of this later: the Setup button becomes ⚙ Settings (top right).
